# 3FTYWHLS — Thrifty Wheels 🚘

**Premium pre-owned vehicles in Nairobi, Kenya.**

A modern, dark-themed car dealership website built with HTML, CSS, and vanilla JavaScript.

## Features
- 🌑 Dark luxury design with amber gold accents

- 🔍 Filter by category (SUV, Sedan, Hybrid, Luxury)

- 💬 One-tap WhatsApp enquiry per car
